# Changelog

## 0.1.0 — first public preview

The first version shared outside the author's Mac.

- Overview of the skills loaded by Claude Code, Codex, Antigravity, DeepSeek Harness, Cursor, OpenCode and Gemini CLI (GitHub Copilot and Devin CLI read-only, shown when installed), with duplicates, differing copies and broken links pointed out.
- Manage a skill: one copy in a git-backed store, linked into each agent you turn it on for; switch it per agent.
- Install from GitHub, a folder or a `.zip`, globally or into a project, with a risk check first.
- Update review every 6 hours that keeps the author's changes apart from your own edits, with merge, keep-mine and take-new options and plain-language risk notes.
- Outside-change detection, History with undo for every change, and agent requests through the `tackroom` command line.
- Read-only MCP overview (secret values never shown), instruction file editing, tags, frequently used skills.
- Interface in 繁體中文, 简体中文 and English.
